# HTML Full Course

An annotated practice page for learning HTML. The source pairs markup examples with comments explaining how the elements are used.

- Document metadata, headings, paragraphs, and text formatting
- Page sections, links, and embedded media
- Lists, tables, and form inputs

## View the examples

Open [the tutorial page](HTML%20Full%20Course/index.html) in a browser, and keep its source open alongside it to read the comments. Some examples reference external or illustrative resources.
